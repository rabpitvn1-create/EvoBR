# StoryForge attribution

EvoBR contains a scoped import of **StoryForge Long Form** from
[yuanbw2025/storyforge](https://github.com/yuanbw2025/storyforge).

Source commit: `9b4cb04be0605f51520fe8fa34eb4e94c2204cd3`.

The original MIT license and copyright notice are preserved verbatim in `LICENSE`.
The source product contract, engineering entry, context routing and data/harness
documentation are preserved in `docs/upstream/`.

The port retains upstream paths wherever practical. `docs/upstream-manifest.json`
records every retained upstream file, its original Git blob SHA, whether its bytes
were adapted, and its current SHA-256. This supports comparison with the pinned source.

The application is a Long Form profile, not a fork of the complete multi-product hub.
See `docs/IMPORT.md` for the actual boundary changes and future integration points.
